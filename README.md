# Desarrollo Web - Coderhouse

Esta carpeta se creó con el fin de mostrar los avances del curso Desarrollo Web de Coderhouse.
En el repositorio se encuentran los avances del proyecto de la página web correspondientes a las entregas 3, 4 y 5. Cada una cuenta con los archivos HTML y las carpetas Pages, Styles e Image.
## Proyecto: Le Contes
Le Contes es un sitio web de una pastelería artesanal desarrollado como proyecto del curso.

- Flexbox
- CSS Grid
